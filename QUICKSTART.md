## 🎨 Customization (Easy!)

### Change Colors
Edit `css/style.css` - Look for:
```css
:root {
    --primary: #0B1F3A;        /* Navy blue */
    --accent: #C9A227;         /* Gold */
    --white: #FFFFFF;
    /* ... and more ... */
}
```

### Change Text
Simply edit `index.html` - No coding needed!
- Find the text you want to change
- Edit it
- Save
- Refresh browser

### Add Your Images
1. Find placeholder images in `assets/images/`
2. Replace with your images (keep same names)
3. That's it!

### Add Hero Video
1. Save your video as `hero-video.mp4`
2. Place in `assets/videos/`
3. Done! The poster image will show while video loads

Choose one of these hosting services:

2. Upload all files to your hosting
3. Set `index.html` as home page

## 🆘 Troubleshooting

### Website Won't Open
- Make sure you're opening `index.html`
- Try right-click → "Open with" → Browser

### Images Don't Show
- Check file paths in `assets/images/`
- Make sure image files are in correct folders
- Refresh browser (Ctrl+F5)

### Video Won't Play
- Add `hero-video.mp4` to `assets/videos/`
- Make sure video format is MP4
- The poster image will show while loading

### Forms Don't Send
- Contact forms are ready for backend setup
- WhatsApp and phone links work immediately
- Email backend can be added later

### Mobile Menu Doesn't Close
- Click any link or click outside menu
- It will close automatically
